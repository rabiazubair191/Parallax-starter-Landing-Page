# Parallax Starter Website 🌌

A modern, fully responsive multi-section landing page featuring smooth scrolling, a frosted glass navigation header, interactive cards, and a sleek contact form.

## 🚀 Features
* **Responsive Design:** Optimized layout for desktop, tablet, and mobile screens with custom CSS media queries.
* **Sticky Navigation:** Frosted glass (`backdrop-filter`) header that stays accessible as you explore the page.
* **Mobile Hamburger Menu:** Interactive mobile navigation menu for clean smaller-screen viewing.
* **Smooth Scrolling:** Seamless anchor navigation (`scroll-behavior: smooth`) across Home, About, Services, Gallery, and Contact sections.
* **Parallax Effects:** Immersive multi-section background styling using CSS backgrounds.

## 🛠️ Built With
* **HTML5**
* **CSS3** (Flexbox, Media Queries, Custom Styling)
* **FontAwesome** (Icons)
